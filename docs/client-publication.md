# Client publication safeguards

For WanoTuts / Kutlwano Tutoring, publication of any direct client quotation,
message screenshot, identifiable conversation, or testimonial requires the
client's explicit approval.

Do not publish telephone numbers, email addresses, WhatsApp timestamps, private
conversation screenshots, payment information, or personal information that
has not already been intentionally made public by the client.

The case study currently uses the permission-safe wording “The proposed name
resonated immediately.” Replace it with a direct quotation only after approval
has been confirmed and recorded.
